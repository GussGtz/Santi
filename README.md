# Santi

Invitación web al cumple 8 de Santi: viernes 16 de octubre, 3:00 PM, Salón de Fiestas Mar (Cancún).

- `index.html`: la página lista para publicar en un hosting.
- `invitacion-santi.html`: la misma página sin el encabezado del documento.
- `supabase.sql`: crea la tabla `confirmaciones` en Supabase.

Para activar las confirmaciones, ejecuta `supabase.sql` en tu proyecto y pon el Project URL y la clave anon en `SUPABASE_URL` y `SUPABASE_ANON_KEY` dentro de la página.
